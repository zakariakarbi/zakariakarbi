## 🚀 Featured Projects

### 🛡️ PHP Webshell Detection via Deep Neural Networks
*AI course project*

I built and trained a **41-layer deep neural network entirely from scratch in NumPy**, with no ML frameworks.

- ⚙️ Implemented backpropagation, He initialization, LeakyReLU, L2 regularization, gradient clipping, momentum SGD, and early stopping
- 🔤 Compared One-Hot, Bag-of-Words, and TF-IDF vectorization of tokenized source code
- 🎯 Reached **95.6% test accuracy** and **95.6% macro-F1**

**Tools:** `Python` `NumPy` `Matplotlib`

### 📊 The Impact of AI Tool Usage on Student Academic Performance
*Team project · supervised by Prof. Lahbani*

A regression analysis built on an **original survey (n = 150)**.

- 🧮 Built a multiple linear regression model with **Forward Stepwise Selection** to measure how AI usage habits predict academic performance
- ✅ Validated all classical assumptions: normality, homoscedasticity, independence, multicollinearity
- 📝 Delivered a full managerial report with policy recommendations

**Tools:** `Python` `statsmodels` `pandas` `scipy` `matplotlib`
